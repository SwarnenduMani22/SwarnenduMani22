I am a Computer Science & Engineering graduate focused on building clean web applications, REST APIs, and AI-driven tools. My work centers on practical full-stack development using the MERN stack alongside Python backend services and Retrieval-Augmented Generation (RAG) pipelines.

- 🎓 **Education:** B.Tech in Computer Science & Engineering
