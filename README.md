## 🚀 Featured Projects

### 📚 StudyTogether — Academic Resource Sharing Platform

A full-stack web application for sharing academic resources, including notes, previous-year question papers, and study materials.

**Key Features**
- User authentication and role-based Admin/User access.
- Resource uploads and administrator approval before publishing.
- Department-, semester-, and subject-based resource filtering.
- MongoDB-backed REST APIs and CRUD operations.
- Responsive interface for academic resource management.
- Coin-based system for user contributions and protected resource access.

**Tech Stack:** React, JavaScript, Tailwind CSS, Node.js, Express.js, MongoDB, REST APIs, JWT
